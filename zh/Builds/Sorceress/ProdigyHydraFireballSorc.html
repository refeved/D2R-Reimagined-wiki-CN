简介

不喜欢阅读就到此为止。抱歉，但不道歉。

九头蛇法师（Hydra Sorc）是游戏里最强的角色之一，但不是在“伤害 go brrr”那种泛指意义上的强。能丢出九头蛇然后撒腿跑、再从远处丢火球，这种能力被严重低估了。然而要说有一个角色能在大多数模组里逃课（cheese）一切，那就是她。就其本身而言她很肉，刷取速度中等、AoE 很小。她在单体、Boss 战和硬内容上大放异彩。

https://www.youtube.com/watch?v=ksXURuSCjo4
 
属性
力量 - 够穿你的装备
敏捷 - 够到最大格挡
体力 - 其余全部
能量 - 练级时可以投一点，但后期为 0

技能
1 点：
冰冷装甲（Frozen Armor）

25 点：  
九头蛇（Hydra）- 构筑名
火球（Fireball）- 构筑名
火焰大师（Fire Mastery）- 法师的属性重地
火弹（Fire Bolt）- 协同

所有技能加满后的剩余点 → 陨石（Meteor）
 

玩法
这个循环从简单到复杂，取决于你在做什么。
上 战斗指挥（BC）、战斗号令（BO）、冰冷装甲、神圣之盾（Holy Shield）→ 走路/传送 → 放九头蛇（数量看你和你要做什么）→ 从安全距离丢火球。
把怪群引到你的九头蛇那里、绕着九头蛇走位，正是这个角色玩起来爽的地方。学会这个你就会觉得有趣，这没法用文字说清楚。

装备与阈值

要达到的重要 BP（阈值）
FHR - 可选 - 从没有到某个舒服档位。在陷入缠斗时很关键。
FCR - 105 FCR 是必须的。这是个重度施法构筑。

武器 - 埃许塔（Eschuta，前期）/ 合成轻刃（Crafted Phase Blade）
合成武器就是太好了。
附魔：+火焰%
镶孔：+火焰 巨型宝石（Colossal Jewel）+全技能 / 切面（Facets），直到 -100 敌人抗

副手 - 凤凰（Phoenix）/ 烈日折磨者（Sun Tormentor）/ 合成 4 孔盾
又是合成最好，这很正常。前期先用其他那些。
镶孔：+全技能 / 切面，直到 -100 敌人抗

盔甲 - 阿卡尼之勇（Arkaine's Valor）/ 合成盔甲
我个人选了阿卡尼之勇。如果你很有钱，合成会很有意思，但一般不需要。

附魔：PDR 或 最大全抗。
镶孔：+全技能 / 切面，直到 -100 敌人抗

头盔 - 吉莉安冠饰（Gillian's Tiara）/ 合成冠冕（Crafted Diadem）
前期用冠饰，它很棒。合成无可匹敌。

附魔：+2 火焰技能
镶孔：+全技能 / 切面，直到 -100 敌人抗

手套 - 燃魂（Burning Soul）/ 合成手套
燃魂在后期之前真的很好。
合成手套能从烂到 BiS。盯着 FCR，其余全都想要。

附魔：FCR

靴子 - 零效（Zero Effect）
一路用零效，想玩得舒服就别合成靴子。

附魔：生命（HP）

腰带 - 卡夏之护（Kashya's Ward）
天生实用，是九头蛇法师不全力堆输出时的防御位。我不推荐其他任何。
游戏里最好的防御腰带，别的连边都沾不上。

附魔：低优先附魔。50HP 或 4PDR。没什么好担心的。

护身符 - 合成 +2 全技能与元素% / 任何带 +2 全技能的暗金
你可以先用任何给你全技能 + QoL 的护身符起步。之后再合成你的第一个，大概会很烂，但先用上并给它附魔。以后再极限优化（Min-Max）。

附魔：+法师技能等级。
 

戒指 - 任意 +技能护身符 / 合成 元素% + 1 全技能
字面意义上任意一个，稀有的也行。我不喜欢乔丹之石（SoJ）并拒绝用它。它就是个 +全技能 的棍子，没半点有用的东西。
合成戒指在后期很棒，如果你运气好，它们会在伤害及更多方面提升你的水平。去做。

附魔：+FCR
