这将是一份关于终局游戏亚马逊物理弓的深入攻略。在 2.0.5 中，这套构筑能让你征服全部内容。它造价高昂，需要大量重掷（reroll）才能得到理想结果。祝你在腐化上运气爆棚。

为远程压制而设计，以多重射击作为主要输出，同时用内在视力削弱敌人防御，让它们更容易被你一击秒杀。我们逐一来拆解：

构筑总览

  • 主力技能：多重射击 / 魔法箭。（80% 的时间用多重射击；在物理免疫较高的区域用魔法箭）
  • 打 Boss 技能：导引箭（穿刺、多段命中、压碎打击 CB）
  • 辅助技能：内在视力（降低敌人防御）
  • 玩法风格：远程、快节奏、范围清场的弓系亚马逊
  • 属性优先级： 全加敏捷， 力量与体力由装备 / 护身符提供
  • 难度：中等；终局游戏需要好装备

技能点分配

重点放在 弓箭与弩 技能树以提升伤害，以及 被动与魔法 技能树以提升实用性。以下是推荐的加点顺序：

核心技能

  1. 多重射击（25 点）
    • 你的主要攻击。以宽阔的弧度射出多支箭，撕碎成群的敌人。把它加满以获得最大伤害输出。
  2. 内在视力（25 点）
    • 在较高等级时显著降低敌人防御，提升你以及你队伍的命中率。为了这套构筑的主题与实用性把它加满。
  3. 导引箭（25 点）
    • 杀 Boss 机器。面对高防御、高生命的怪物或 Boss 时使用。该技能会命中多次并施加所有 debuff。
  4. 魔法箭（1 点）
    • 在不同幕清场比多重射击更好用。
  5. 致命一击（5-10 点）
    • 提升你造成双倍伤害的几率。由于收益递减，这里几点就很有用。（装备上的致命一击 DS 会与它很好地协同）
  6. 穿刺（5-10 点）
    • 让你的箭能穿过敌人，每次射击命中多个目标。与多重射击完美协同。目标是通过装备达到 50-70% 穿刺几率。（箭袋会给你 +25% 穿刺，所以技能树里堆到 75% 即可。不要用任何其他装备去凑穿刺）
  7. 穿透（5-10 点）
    • 提升你的攻击评级（AR），确保多重射击稳定命中。

可选 / 辅助技能

  • 闪避 / 规避 / 回避（各 1 点）
    • 这些被动减少你受到的近战、远程伤害，以及移动时受到的伤害。有了 +技能，各 1 点就够。

加点方案

  • 到 80-90 级时，目标为：
    • 25 多重射击
    • 25 内在视力
    • 5 导引箭
    • 10 致命一击
    • 1 穿刺
    • 10 穿透（对维持 AR 很重要）
    • 1 闪避、规避、回避
    • 剩余点数：根据装备投情境技能。

属性点分配

  • 力量：所有力量都来自制作的巨型护身符。护身符上找力量来穿装备、找敏捷来打伤害。% 武器 ED
  • 敏捷：主属性。堆它来获取伤害和攻击评级。
  • 体力：体力由制作的巨型护身符提供。（如有需要，可把装备 roll 换成体力）
  • 能量：0 点。

装备推荐

优先物理伤害、攻击速度和续航。找这些属性：+% 增强伤害、+% 攻击速度（IAS），以及 % 压碎打击 / % 致命一击。

武器（可升级 10 次）

  • 这是最重要的物品。[也许有更强的制作弩]
  • 精金（暗金 九头蛇弓）
  • 腐化出 50-100 最小 / 最大伤害
  • 用附魔把增强伤害（ED）做到 511%（这可能要花 20-30 个 uber 之魂，取决于你的武器 roll / 制作。把这一项 roll 对极其重要）
  • 用镶孔魔球开出 6 孔
  • 插入带 % 攻击速度 / 致命一击的增强伤害宝石

胸甲（可升级 5 次）

  • 刚毅（EL + SOL + DOL + LO）
    • 大幅提升伤害与防御。纯进攻的不二之选。
    • 腐化出抗性上限
    • 用 抗上限 x5 升级

头盔（可升级 3 次）

  • 暗金 - 审判者之盔（Judge's Helmet）- 加伤害不错，可根据你最终的属性需求替换。
  • 提升伤害，纯进攻的不二之选。
  • 腐化出物理伤害抗性 // 提升攻击速度
  • 用 +4% 伤害减轻 升级 x3

手套（可升级 3 次）

  • 手掌的安置
    • 攻速（IAS）与 +350% 对恶魔伤害。对绝大多数内容都非常惊艳。
    • 腐化出 20% 增强伤害与攻击速度。
    • 用压碎打击 / 致命一击升级
  • 压碎打击
  • 致命一击

 

腰带

  • 野蛮人的拥抱（人都死了就打不出伤害， 不是每件装备都得是伤害）
  • 提供 1 级钢铁装甲（Iron Skin）来拉高防御（降低被命中几率）
  • 海量力量与体力提升，100 级时 +100。
  • 100% 毒素抗性。
  • 腐化出物理伤害与魔法抗性
  • 用 伤害减轻 // 全抗 升级（取决于装备，我用的是伤害减轻）

靴子

  • 种马之蹄
    • 跑速、快速打击恢复（FHR）、固定伤害、压碎打击、致命一击。（这是梦幻配置靴）
    • 腐化出 FHR / 跑速。
    • 用敏捷与体力升级

戒指 / 项链

  • 炽天使之戒 x2：全技能、增强伤害、击杀后获得生命（这是一件过渡物品，可根据你的需求调整）
  • 腐化出法力 / 生命偷取
  • 腐化出抗上限 / 全抗
  • 用 物理伤害减轻 / 全抗 / 攻击速度 升级

项链 （我这里还差 37% 增强伤害）

  • 征服者 ：190-200% 增强伤害。（别盯着我那根烂项链看啊）
  • 腐化出 % 增强伤害 或 全抗 / 抗上限
  • 用敏捷 / 体力升级

护身符

 

  • 黑色灵魂石（强化 annihilus）敏捷很香。
  • 黑曜石信标（强化火炬）敏捷很香。
  • 制作 敏捷 + % 增强伤害 巨型护身符。（你能做到 40% 甚至更高 + 固定伤害 + 敏捷）
  • 一枚物理破免护身符，制作为 全抗 / 生命 / 敏捷

玩法贴士

  1. 走位：传送到房间里，施放内在视力，用多重射击开火，然后收获。
  2. 回血： 切到箭雨，一击应该就能回满 100% 生命
  3. 内在视力的使用：频繁对怪群施放以降低它们的防御，尤其针对 Boss 或高防御的怪物。 #######一击秒杀 swagger 拉满 9999%#######
  4. 法力管理：依靠装备的法力吸血。如有需要，加一条“击杀回法力”。
  5. 物理免疫：制作物理破免护身符，带 固定伤害 / 弓技能 / 全抗
  6. 刷图区域：第五幕 halls 1-3 刷经验，钥匙来自 尼拉塞卡。

优缺点

优点：

  • 能通关全部内容、Uber、地狱恐刷区（TZ）、快速升到 100 级、极端刷宝石

打古代 Uber 需要在防御上做大幅调整。加救赎（Salvation）灵气，或把抗性堆过上限。

缺点：

  • 依赖装备 （终局游戏，地狱难度）。
