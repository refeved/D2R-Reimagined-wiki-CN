# 地图词缀与奖励

地图词缀告诉你这一轮与同主题同层级的另一张地图有何不同。开图前先查看悬浮说明，进图后借助图内界面持续掌握生效中的效果。

## 更多怪物与精英

| 词缀 | 效果 |
| --- | --- |
| **滋生（Teeming）** | 怪物更多。 |
| **蜂拥（Swarming）** | 怪物密度大幅提升，并追加精英群。 |
| **传奇辈出（Storied）** | 精英群更多。 |
| **史诗（Legendary）** | 精英群大幅增加，并附带额外怪物密度。 |

敌人更多意味着掉落机会更多，但对你的防御压力也更大。许多战斗类词缀同时会提升密度和精英数量，要看词缀名字，也要综合地图的整体加成。

## 玩家惩罚

| 词缀 | 效果 |
| --- | --- |
| **衰蚀（Sapping）** | 物理攻击伤害加成 −15 个百分点。 |
| **凋零（Withering）** | 物理攻击伤害加成 −30 个百分点。 |
| **渎神（Unhallowed）** | 所有技能 −2。 |
| **脆弱（of Frailty）** | 火、冰、电、毒抗性 −30。 |
| **破灭（of Ruin）** | 火、冰、电、毒抗性 −60。 |
| **痛苦（of Agony）** | 物理抗性 −25。 |

衰蚀和凋零削减的是物理攻击伤害加成，并不是说你所有伤害来源都乘 0.85 或 0.70。法术伤害不受它们影响。

这些只是地图内的临时效果，不会永久改变你的角色。按悬浮说明标注的范围理解：**全图**惩罚在主区域和守卫者竞技场全程生效；说明写着**靠近怪物时**的，只在该距离内生效。

超出面板上限的额外抗性可以帮你扛住脆弱或破灭。痛苦作用于物理抗性，与四种元素抗性彼此独立。

## 怪物光环

| 词缀 | 效果 |
| --- | --- |
| **审判（of Conviction）** | 怪物携带 10 级审判光环，威胁你的元素抗性和防御。 |
| **力量（of Might）** | 怪物携带 12 级力量光环，提升物理攻击伤害。 |
| **狂热（of Fanaticism）** | 怪物携带 10 级狂热光环，让依靠攻击的怪物群更加危险。 |

这些光环与主题守卫者自身的技能是叠加关系。给受光环加持的怪物群留出空间，尤其是多个敌人能同时打到你时。

## 怪物组成与攻击词缀

| 词缀 | 效果 |
| --- | --- |
| **奶牛入侵（Bovine Incursion）** | 部分怪物群被地狱奶牛替换。 |
| **女巫集会（Witch Coven）** | 部分怪物群被魅魔替换。 |
| **不安军团（Restless Legion）** | 部分怪物群被白骨弓箭手替换。 |
| **血狂（Blood Frenzy）** | 地图普通怪物获得 15% 移动速度和攻击速度。 |
| **火焰契约（Flame Pact）** | 地图普通怪物每级地图附加 20–40 点火伤害攻击。 |
| **冰霜契约（Frost Pact）** | 地图普通怪物每级地图附加 15–30 点冷伤害攻击。 |
| **风暴契约（Storm Pact）** | 地图普通怪物每级地图附加 5–60 点闪电伤害攻击。 |

怪物组成词缀会替换地图的部分怪物。血狂和元素契约同样影响守卫者的普通随从，但不会替换守卫者自身的技能。

举例：火焰契约在 3 级地图附加 60–120 点火伤害攻击。这是怪物攻击上的额外元素伤害，请准备相应抗性。

## 奖励词缀

| 词缀 | 效果 |
| --- | --- |
| **流金（Gilded）** | 精英怪物额外判定掉落金币、宝石、赫拉迪克魔球或奥秘圣物。 |
| **工匠（Artificer's）** | 精英怪物额外判定掉落宝石、珠宝或装备。 |

这些只是精英怪物上的额外判定机会，不是每次击杀都保底多掉一件。它们不会让守卫者奖励翻倍，也不会提高宝藏怪物的遭遇频率。

## 战斗魔法寻找

地图在你与附近地图怪物战斗时提供**战斗魔法寻找加成**。它随层级和词缀强度增长，**地图本身最高 +250%**。查看悬浮说明或图内界面，了解本轮的加成数值。

它通过常规的魔法寻找规则提升物品品质，不是永久角色加成，也不会按百分比增加掉落数量。更高层级还会提高常规掉落概率，而密度和精英数量的提升意味着更多可搜刮的敌人。

## 如何挑选随机结果

层级越高，随出的词缀越多：1 级到 6 级依次为 **1 / 1–2 / 2 / 2–3 / 3 / 4**。有些词缀只在较高层级才会出现，也不是所有组合都能刷到。

选你的构筑能稳定通关的难度。如果组合看起来很凶，在开图前用**一张地图 + 一颗奥秘圣物**在地狱难度下放进方块重随。完整配方见[合成与进阶](/en/maps/crafting)。
