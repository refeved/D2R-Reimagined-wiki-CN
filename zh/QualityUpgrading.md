# 升级你的防具或武器品质	

在本作中，了解物品品质非常重要。本文会介绍如何使用 Reimagined 的方块公式提升品质，并覆盖升级防具或武器能显著强化角色或佣兵的主要场景。页面底部附有一些升级前后对比图，你可以直观看到几件武器和一件防具的差别。如果你已经捡到了一颗转化魔球（Orb of Conversion），想赌一把特定的暗金盔甲或武器，那你来对地方了。

> 警告：用公式把 [N] 升到 [X] 或把 [X] 升到 [E] 时，物品的等级、力量、敏捷需求往往会一起提高！ 升级过程中如果手上正好有两把相同的武器，那么升级其中一把是非常不错的——万一级数要求太高，你还可以继续用没升级的那把。
{.is-warning}




## 品质类型说明
[N] = 普通（Normal）
[X] = 扩展（Exceptional）
[E] = 精英（Elite，*最好*）

品质共分三档：[N] 等级需求最低、防具防御最低、武器伤害最弱；[E] 等级需求最高、防具防御最高、武器伤害最高。在本模组中，所有物品都用这几个字母标注品质。

需要注意的是，即使同属 [E] 精英档，防具与武器之间也互不等价。 制作符文之语时，挑选底材要特别留意力量与敏捷需求。 虽然随便找一件白色胸甲打孔也行，但野蛮人应该尽量找防御最高的底材，也就是 [E] 圣殿铠甲（Sacred Armor）。

部分单手、双手与远程武器的基础伤害天生更高，与「增强伤害%」词缀的乘算收益也格外出色。 暴雪通常给这类武器配上较慢的攻击速度，但在 Reimagined 中，物品升级/护身符/珠宝/符文都能帮你凑够攻速档位。 升级途中用弱底材配超高增强伤害%完全没问题，但 *到了终局，目标应该是让你的职业所能装备的最高伤害远程底材穿上符文之语或终局手工装。*

## 什么时候该选某种防具或武器底材

你要做一件打算长期使用的符文之语（尤其是武器）。
你手上有转化魔球，想 **赌某件特定暗金**。
你手上有组装魔球（Orb of Assemblage），想 **赌某件特定套装**。
你手上有注魔魔球（Orb of Infusion），想要最好的稀有装备——选对底材是关键。
你要用暗金珠宝 + 高等符文做手工武器或防具。

举个例子：一件胸甲底材防御 200，如果符文之语给 +200% 增强防御，最终防御就是 600。 而另一件底材防御 500，同样 +200% 增强防御就能达到 1500！ 对物理伤害职业来说，选武器同理——伤害是从底材成长的。 用暗影魔球（Orb of Shadows）或暗金珠宝公式强制做出无形装备还会进一步放大底材优势，所以选好底材更加重要。

### 野蛮人能用的最高伤害双手底材武器是什么？
看平均伤害，简称 "av"：最低伤害加最高伤害再除以二。  

比较仅有的两把 [E] 精英双手锤：

 食人魔巨槌（Ogre Maul）77-106 伤害 *(91.5av)*
雷霆巨槌（Thunder Maul）33-180 *(106.5av)*

野蛮人最高伤害的双手武器是精英品质的双手锤雷霆巨槌。 还有剑等其他双手类型，但平均伤害都更低。 下面这个资料很好用，可以查看每种武器的最大孔数与武器速度。

https://www.wowhead.com/diablo-2/guide/hammer-socketed-base-items-for-runewords

### 第二幕佣兵能用的最高伤害双手底材武器是什么？
精英 [E] 品质的双手矛「战争刺枪（War Pike）」，105.5av，第二幕佣兵遥遥领先的第一选择！

第二、第三高的矛只有可怜的 86.5av
最好的长杆底材也只有 91.5av

以往玩家普遍认为佣兵用弱一点但攻速快的武器最好，但那个结论来自于没有模组、攻速又低、只在 P1 联机的佣兵。 好好利用 Reimagined 的物品升级系统和大幅扩充的符文之语与暗金选择，很快你就会发现，你和佣兵都能轻松摸到全部攻速档位。

## 在 Reimagined 里你可以做什么
可以把稀有、套装或暗金从 [N] 升到 [X]
可以把稀有、套装或暗金从 [X] 升到 [E]

可以用 HEL+EL 公式把灰色或魔法物品变成白色。
然后用注魔魔球把白色变成稀有，这样就获得了可升 [X] 或 [E] 的底材。

利用游戏里的赌博系统，玩家可以快速拿到任意指定物品并把底材升到你要的那一档：强制变白，用魔法珠宝凿出符文之语需要的孔数；或者强制变稀有，再用魔球赌它变成某件特定的暗金或套装。 终局手工公式威力出众，但材料成本极高，所以底材要深思熟虑——随机手工出的成品完全取决于底材。

## 实例：为转化魔球准备特定底材
假设你捡到一颗「转化魔球」，想要暗金胸甲「Tarrasque Hide（鲲甲）」。

先在 Reimagined 官网上查这件暗金的属性，下图中可以看到它的底材是骸骨织甲（Boneweave）。
![boneweave1.jpg](/qualityupgrading/boneweave1.jpg)
可以查询的网站很多，本文以 purediablo 为例，进入它的「Armor」或「Weapons」板块即可。 https://www.purediablo.com/diablo-2

我们要找的是 Boneweave 胸甲，下面是点击网站「Body Armor」后的示例。
https://www.purediablo.com/diablo-2/diablo-2-body-armor

网站截图如下：
![boneweaver2.jpg](/qualityupgrading/boneweaver2.jpg)
如上图所示，N、X、E 三档各有 15 种胸甲。

查找「Boneweave」后会发现它是精英 [E] 物品，网站上排在 4.8。点击名字还能看到它游戏内的底材外观，见下一张图。
![boneweaver3.jpg](/qualityupgrading/boneweaver3.jpg)
现在回到列表，不点 4.8，而是点 2.8「Chain Mail（锁链甲）」。这正是同一款防具的普通 [N] 版本，外观图形完全一致——无论是刷地面掉落还是赌博找装备都更容易辨认。有了这个信息，去赌博商人那里反复赌「Chain Mail」，赌出蓝色魔法版本后用 HEL+EL 变白，再用注魔魔球强制变稀有；或者赌出任意品质的稀有版，直接把它升到 [X] 或 [E]。
![boneweaver4.jpg](/qualityupgrading/boneweaver4.jpg)
说明一下：向商人赌「Chain Mail」时，随机出现的永远是这三档之一：
[N] = Chain Mail（锁链甲）
[X] = Mesh Armor（鳞纹甲）
[E] = Boneweave（骸骨织甲）

网站上只有两件 Boneweave 暗金，但由于稀有度权重，使用转化魔球时并不是两件各 50% 的概率。 你可以花上几小时甚至几天去地面刷特定底材，但靠赌博强制制造底材来配合魔球或手工需求，才是更快的路子！

武器同理，同一款武器也有三种品质版本。 理解了这套系统、知道三个版本的游戏内模型完全相同之后，找到你想要的底材就又快又轻松！

# 升级途中就把装备升到 [X] 或 [E]，差别巨大
下面分别给出野蛮人和第二幕佣兵升级途中的几个例子，展示武器上的增强伤害%如何直接随底材放大——升级物理伤害武器的底材会让你的输出发生质变！ 但也要格外小心，不同物品的等级要求各不相同。

升级途中提升武器或胸甲底材品质的最佳时机，是当你找到两件相同的暗金或套装时。 比如你有两把一模一样的暗金武器，可以把其中一把从 [N] 升到 [X]：也许等级要求只 +3，立刻就能用；也可能 +15，当前等级突然穿不上了！ 别担心，你还有第二把，这一把留着到等级就够了再换装。 下图展示了这些重做后的底材升级有多强！

注意两件都是同一款暗金武器，只不过其中一件的品质从 [N] 升到了 [X]。

## 升级途中最值得升级的三件装备
你的单手、双手或武器升级效果极佳！ 不仅伤害显著更高，[X] 或 [E] 版本用镶嵌魔球（Orb of Socketing）打孔时还可能允许更多孔位。

你的胸甲也很值得升级！ 不仅总防御大幅上涨，[X] 或 [E] 版本用镶嵌魔球打孔时最多可达 4 孔。

你的头盔！ 常见暗黑站子上多数头盔不允许 4 孔，但在 Reimagined 中，大多数 [E] 精英头盔被改成可以打 4 孔。

有些暗金和套装腰带非常出色，可惜只能让角色携带 4 瓶或 8 瓶药水。 现在这个问题已获解决：把底材升到 [X] 或 [E]，穿上即可携带完整的 16 瓶药水。
