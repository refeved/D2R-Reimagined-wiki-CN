用启动器安装，或手动安装 Reimagined

 

Reimagined 启动器（非常简单）可安装在 Windows 上并自动更新，可在 Nexus Mods 下载。它可以一键找到线上最新的 Reimagined 版本，还会自动备份你的存档。

 

手动按步骤安装（简单/困难）：你需要自己找到游戏安装目录，并且要自己负责备份存档——万一读图时崩溃，后果自负。

 

默认文件位置 —— 取决于你在战网客户端还是 Steam 购买

C: 盘是最常见的安装位置，你的实际路径可能因环境不同而不同。启动器会自动找到它们。

战网版 D2R 模组文件： C:\Program Files (x86)\Diablo II Resurrected\mods\Reimagined

Steam 版 D2R 模组文件： C:\Program Files (x86)\Steam\steamapps\common\Diablo II Resurrected\mods\Reimagined

存档文件： C:\Users\%USERPROFILE%\Saved Games\Diablo II Resurrected\mods\ReimaginedThree

Reimagined 与 D2RLoader

视频教程在这里：

D2RLoader 为 Reimagined 提供局域网 TCP/IP 联机支持，包括术士统治（ROTW）内容，而且去掉了原先的职业与机制限制。
D2RLoader 还能实现上百个共享仓库页签等功能，其它设置见这里。

注意：D2RLoader 仍在积极开发中，安装步骤和配置选项可能在未来版本中变化。

开始之前：所有加入同一个 TCP/IP 游戏的人，必须使用相互匹配的 D2R、D2RLoader、D2RLoader 插件/补丁、Reimagined 兼容版本，以及相同的 Reimagined 启动器调节项或对文件的插件/改动。

1. 先装好 Reimagined 启动器

  • 安装 Reimagined 启动器，见本页开头

安装完成后，你应该能看到类似这样的界面，其中有离线或联机的选项

 

2. 点击 Online，让启动器帮你安装 D2RLoader

  • 直接点 Online 按钮，它会检查 D2RLoader 是否已安装。
  • 如果没有安装，启动器会自动下载并安装

 

  • D2RLoader 安装完成后会提示已完成

 

 

3. 启用多人游戏组件

  • 截至本文撰写时，多人游戏按钮组件还不会自动加到模组界面里（未来的启动器版本会处理这一步）
  • 所以请点「Start Online」按钮，带上 D2RLoader 启动游戏
  • 游戏启动后，点击底部的红色齿轮
  • 然后启用多人游戏按钮
  • 这时你会看到多人游戏按钮，可以用它建房和浏览房间

  • 如果开的是不公开的私人房间，房主需要在队伍菜单里把房间 ID 发给对方。

 

  • 搞定，现在你就能和朋友一起玩最新版本、带 ROTW 内容的 Reimagined 了

 

4.5 调整共享仓库页签数量

  • 然后进入 gameplay 页签，调整共享仓库页签数量和材料堆叠上限（ROTW 的符文/宝石/材料页签）

 

  • 设置完成后进游戏查看，共享仓库页签上限应该已经提高了

手动安装 Reimagined 模组

不使用任何启动器或辅助程序，手动安装 Reimagined 模组的步骤。

第 1 步。 从 Nexus Mods 下载最新的 Reimagined 模组版本。

 

第 2 步。 进入你的 D2R 安装目录，在左上角空白处点一下再右键，让路径被高亮。然后右键点 复制，这段路径在后面的第 4 步会用到。接着打开名为「mods」的文件夹。你游戏的实际安装位置会和图片里不同。 

 

第 3 步。 在 mods 文件夹里检查是否已有旧的 Reimagined 文件夹，如果有就删除它，因为你要装一个全新的版本。（右键 → 删除）

 

第 4 步。 进入你刚下载模组的位置，默认通常在「下载」文件夹里。你会看到刚下载的、以「D2R Reimagined」加版本号开头的新 ZIP 文件。下图以 Reimagined 3.0.5 为例。

 

第 5 步。 右键点击该 ZIP 文件，选择全部解压缩 

 

  • Windows 11 用户请点 显示更多选项 来完成上面的操作。

 

 

第 6 步。 在弹出的窗口里右键点击路径栏，选择粘贴。此时目标位置应该就是你之前复制的那个路径。同样，你的实际位置会和下图不同。然后点解压缩按钮，Reimagined 模组就装好了！

 

 

第 7 步。 接下来创建一个用来启动模组的快捷方式。回到第 2 步里的游戏安装目录，右键点击 D2R.exe，选择发送到，再选桌面（创建快捷方式）

  • W11 用户请点 显示更多选项 来完成上面的操作。
  • 右键点击桌面上的快捷方式，选择属性
  • 在「目标」一栏的末尾追加以下内容：
    •  -mod Reimagined -txt
    •  -mod Reimagined -txt -resetofflinemaps （可选：每次进入角色选择界面都会重置地图）
  • 确认 D2R.exe" 与 -mod 之间有空格
  • 点应用，再点确定

 

第 6 步。 你可以把快捷方式改成任意名字，然后点击或双击它来玩模组。Reimagined 已经装好，可以开始玩了！

 

如果你想手动安装 6 个自定义小补丁中的任意一个（2skill、强制恐惧地带、移除光环音效、HDR 修复、移除黑边、移除溅射护身符特效），这些文件也打包在本页靠上位置的 Beta 启动器 ZIP 里，供手动安装的玩家使用。如果你只想要 2Skill 文件，直接下载下面那个文件即可。

 

D2RMM

用模组管理器可以很方便地同时安装多个模组（前提是它们互不冲突），完全不需要了解模组制作知识。

Reimagined 本身已经集成了大量功能和生活质量改动，所以并不总是需要额外装模组。 

先看看下面这份 Reimagined 功能列表，确认是否还需要第三方模组。

 

使用 D2RMM 后，生效的模组文件会位于 D2RMM\mods\ 文件夹，而不是 Diablo II Resurrected\mods\。

你对 Reimagined 文件的任何改动都需要在 D2RMM 的 mods 目录下进行。
 

文件操作步骤

1. 从 D2RMM 的 Github 下载 D2RMM。

2. 打开 D2RMM 文件夹，进入 mods 目录。

  • 你应该会看到一个名为「PUT YOUR MODS HERE」的文本文件——先别关这个窗口，稍后要用。

3. 再开一个资源管理器窗口，进入 D2R 安装目录下的 Reimagined 模组文件夹。

4. 复制 Reimagined.mpq 文件夹（里面应该有一个 Data 文件夹和 ModInfo.json）。

5. 把 Reimagined.mpq 文件夹粘贴到第 2 步打开的 D2RMM/mods 文件夹里。

  • 建议把文件夹改名为 Reimagined

D2RMM 操作步骤

6. 以管理员身份运行 D2RMM。

7. 打开后点击右下角的三个点，选择「刷新模组列表（Refresh Mod List）」。

8. Reimagined 应该会出现在模组列表里——点击左侧的方框启用它。

Reimagined 文件夹必须始终排在模组列表的第一位。如果不是，请按住那条线拖到最上面。

9. 进入顶部的 Settings 页签。

  • 9a. 点击 General。
    • 把「Output Mod Name」改成「Reimagined」。
    • 打开「Automatically install mods before running the game」。
  • 9b. 点击 Game Launcher。
    • 在「Extra Game Args」里粘贴：-mod Reimagined -txt
    • 可以在后面随意追加其它参数。

10. 回到 Mods 页签。

11. 点击 Install Mods。
 

开始玩！

12. 点击「Run D2R」。
 

掉落过滤器

本指南假定你已经下载并安装好 D2RMM（见上文）

  • 由于有术士 DLC，我们建议直接使用游戏内的掉落过滤系统，它兼容我们的财宝文件、字符串和模组新增物品。
  • 对于没有 DLC 的玩家，下面这个过滤器以及 Nexus 上类似的过滤器都属于自行承担风险的用法，Reimagined 不提供支持。模组改动了这些过滤器涉及的每一个文件，作者需要专门为 Reimagined 出一个版本，才能完全兼容、不出问题。
     

文件操作步骤

1. 从 Nexus Mods 下载 Pseudo Loot Filter。

  • 选择「Mod manager download」可自动下载并载入 D2RMM。
  • 选择「Manual download」会把模组下到你的 Downloads 文件夹——请手动把模组解压到 D2RMM/mods 文件夹。
     

D2RMM 操作步骤

2. 在 D2RMM 里点击右下角的三个点，选择「刷新模组列表（Refresh Mod List）」。

3. 这时你应该能在模组列表里看到 Pseudo Loot Filter——点击左侧方框启用它。

4. 要配置过滤器，点击右侧的「settings」。

5. 所有物品默认都是启用的（滑块在右侧）——点击滑块会「禁用」该物品（对白色、魔法、稀有、套装、暗金所有品质都生效）。

  • 禁用一个物品的意思是：本该掉落这件物品时，游戏改为不掉落任何东西。
  • 禁用物品不会影响其它物品的掉率。
  • 可能要刷几局才能把这份列表调到你满意的样子。

6. 把不想要的物品禁用完之后，点空白处退出菜单。

7. 点击右下角的「Install Mods」。

8. 点击「Run D2R」。

频繁崩溃？排查建议

以下是我们从 Discord、Nexus 和 Reddit 的 bug 反馈里总结出的一些常见解决办法。

1. Reimagined 3.0+ 不兼容 Reimagined 1.x.x、Reimagined 2.x.x、原版 D2R 或其它模组的存档（只要存档里带物品）。把这类存档放进存档文件夹并使用，通常会导致游戏崩溃。

2. 无法创建经典模式角色，它与模组不兼容。

3. 把画质选项里的「VFX Lighting Quality」从 Ultra 调到 High 或 Medium，它对画面几乎没有影响，却会严重拖性能并导致崩溃。

4. 把帧率限制在显示器刷新率，并/或开启垂直同步（Vsync）。

5. 不要 Alt + Tab 切出（窗口模式下点击屏幕外同理），游戏不喜欢失焦。可以通过显卡控制面板限制 D2R.exe 的后台帧率来缓解这个崩溃。（游戏仍然会崩，但限制后台帧率能降低频率。）

6. 不要给雇佣兵装备带「施法时召唤随从」这类 CTC 的物品。（「复活」没问题，问题通常出在 CTC 上。）

7. 把电源模式从「高性能」改为「平衡」（不太直观，但对部分玩家有效。）

8. 如果你还用了其它模组，可以试着禁用它们看看崩溃是否继续；但如果它们改动了 itemstatcost.txt，禁用同样会导致崩溃，所以请注意你在做什么，实验前先备份。

9. 如果你自己改过模组文件，请撤销改动或重新干净地安装一遍模组。
