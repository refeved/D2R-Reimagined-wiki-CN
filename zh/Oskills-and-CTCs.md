# Oskill 与 CTC 专属技能

## Oskill（装备技能等级）
### 什么是 Oskill？
Oskill（+X 技能等级）对技能所属职业本身最多只提供 +3 级，同一件装备上多个来源的相同 Oskill 也计入这 +3 的上限。其他职业则可以享受全部加成。

如果 +X 技能等级后标注了（仅限某职业 / Class Only），则只有该职业能从技能等级提升中受益，并获得完整效果。

更多资料见[这里](https://www.theamazonbasin.com/wiki/index.php/Oskill)和[这里](https://diablo.fandom.com/wiki/Oskill#Same_class_cap)。

## CTC 技能

### 什么是 CTC？
CTC 是 chance to cast（触发施法）的缩写。它是一种机制：在满足指定概率与技能等级时，自动触发另一个技能。

协同加成对 CTC 技能有效。CTC 技能本身的等级无法提升，但你可以在多件装备上叠加相同的 CTC 技能与触发事件，来提高触发概率。

触发 CTC 技能的事件有多种：攻击时（on attack）、击中时（on striking，成功命中）、被击中时（when struck）、死亡时、升级时、击杀敌人时。

注1：击杀敌人触发的 CTC 只对武器伤害、武器或毒素伤害、以及开放伤口（open wounds）生效，法术不会触发 CTC 技能。
注2：被击中（when struck）指实际受到伤害，格挡成功不会触发该类 CTC。

更详细的说明见 Amazon Basin 页面：[这里](https://www.theamazonbasin.com/wiki/index.php/Chance_to_Cast)
